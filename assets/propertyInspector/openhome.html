OpenHome

Connection details are shared across this plugin and are saved only when you select Save and connect. Device discovery is cached in the Rust plugin process and shared by all actions.

Homebridge control

Runs the same toggle operation as pressing the physical OpenDeck key.

Brightness behaviour

Rotating an encoder always adjusts brightness relatively. A key press or encoder press uses the selected mode.

Each encoder tick changes the value by Homebridge's minimum step multiplied by this number.

Homebridge requirement

Homebridge Config UI must be reachable, and Homebridge must run in insecure mode (-I) so the UI accessory-control API can read and write characteristics. Keep port 8581 on a trusted network.
